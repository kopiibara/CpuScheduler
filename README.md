CpuScheduler_v2

CpuScheduler_v2 is a modern desktop application built using Electron, React, and Python that allows users to view and manage running processes, modify CPU affinity and priority, and simulate CPU scheduling algorithms like First-Come, First-Served (FCFS).


 Features
 Real-Time Process Fetching
View detailed information about active processes on your system.

 Modify CPU Affinity
Assign specific CPU cores to any process.

 Change Process Priority
Dynamically adjust the execution priority of selected processes.

 FCFS Scheduling Simulation
Simulate the First-Come, First-Served (FCFS) algorithm with visualization support.

 Cross-Platform Desktop App
Built using Electron with a React frontend and Python backend for system operations.
